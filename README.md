# KinoBudka

Сайт для совместного просмотра видео с друзьями. Его можно запустить на своём компьютере
и пустить друзей через Hamachi / Radmin VPN / локальную сеть — как сервер игры.

## Запуск

Нужен Python 3.10 или новее.

**Windows** — двойной клик по `run.bat`. При первом запуске он сам создаст окружение
и поставит библиотеки.

**Linux / macOS**

```bash
./start.sh
```

**Вручную**

```bash
pip install -r requirements.txt
python main.py
```

После запуска в консоли появятся адреса:

```
  KinoBudka запущена
  У себя открывайте:   http://localhost:5000
  Друзьям (Hamachi): http://25.34.56.78:5000
```

Себе открывайте `localhost`, друзьям отправляйте адрес из строки «Друзьям».
Если Windows спросит про доступ Python к сети — разрешите, иначе друзья сайт не увидят.
Предупреждение `This is a development server` в консоли — это нормально для запуска «для своих».

## Как смотреть вместе

1. Создайте комнату: страница **YouTube** (ссылка на ролик или прямая ссылка на видео)
   или **Фильмы → Моя медиатека** (свой файл).
2. В комнате нажмите **«Ссылка для друзей»** и отправьте её. Друг открывает ссылку,
   вводит имя — и он в комнате.
3. Видео управляет **только админ** — тот, кто создал комнату. Пуск, пауза, перемотка
   и скорость у всех остальных повторяются сами; у зрителей есть только громкость
   и полный экран. Сервер не принимает команды плееру ни от кого, кроме админа.

Админ также может: сменить видео, не пересоздавая комнату; сделать комнату открытой
(видна на главной) или закрытой (вход только по ссылке); передать управление другому
зрителю; исключить зрителя; завершить комнату.

Писать в чат могут вошедшие в аккаунт.

## Что можно смотреть

| Источник | Как добавить | Синхронизация |
| --- | --- | --- |
| YouTube | ссылка на ролик | да |
| Видео по ссылке | прямая ссылка на `.mp4` / `.webm` или поток `.m3u8` | да |
| Свой файл | положить в папку `media` | да |
| Фильм из каталога | страница «Фильмы» | нет — это чужой встроенный плеер, каждый запускает сам |

### Свои файлы

Положите видео в папку `media` рядом с сайтом — они появятся на странице «Фильмы»
в блоке «Моя медиатека». Надёжнее всего MP4 (H.264 + AAC): его открывают все браузеры.
Файл раздаётся с вашего компьютера, поэтому качество у друзей зависит от вашей
скорости отдачи.

## Настройки

Задаются переменными окружения перед запуском (в Windows: `set ИМЯ=значение`).

| Переменная | Что делает | По умолчанию |
| --- | --- | --- |
| `KINOBUDKA_PORT` | порт сайта | `5000` |
| `KINOBUDKA_HOST` | `0.0.0.0` — виден друзьям, `127.0.0.1` — только вам | `0.0.0.0` |
| `KINOBUDKA_MEDIA` | папка со своими видео, например `D:\Фильмы` | `media` |
| `KINOBUDKA_ROOM_TTL` | через сколько секунд удаляется пустая комната | `600` |
| `KINOBUDKA_SECRET_KEY` | секретный ключ сессий | создаётся сам в `instance/secret_key` |
| `KINOBUDKA_DEBUG` | `1` — режим отладки Flask (не включайте, когда сайт открыт друзьям) | выключен |

## Устройство проекта

- `main.py` — страницы сайта и события комнат (Socket.IO)
- `setting.py` — настройки
- `config/rooms.py` — комнаты: таймлайн видео, права админа, участники
- `config/media.py` — источники видео (YouTube, ссылки, свои файлы)
- `static/js/kb-player.js` — свой плеер, `static/js/room.js` — страница комнаты
- `static/css/main.css` — общая чёрно-фиолетовая тема, остальные файлы — стили страниц
- `templates/` — шаблоны страниц

Админка сайта — `/admin` (для пользователей с ролью `admin`).

В `static/` лежат сторонние библиотеки: Socket.IO client (MIT), hls.js (Apache-2.0),
шрифты Manrope и Unbounded (SIL OFL 1.1).
