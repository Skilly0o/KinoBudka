Сюда кладите свои видео — они появятся на странице «Фильмы» в блоке «Моя медиатека».

Подходят файлы .mp4, .m4v, .webm, .mkv, .mov, .ogv. Надёжнее всего MP4 (H.264 + AAC):
его открывают все браузеры. Можно раскладывать видео по вложенным папкам.

Другая папка: задайте переменную окружения KINOBUDKA_MEDIA, например
    set KINOBUDKA_MEDIA=D:\Фильмы
